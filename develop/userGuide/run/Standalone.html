Running Standalone

Partly written

This page does not yet walk through setting up and running a standalone case. Progress is tracked in E3SM-Project/Omega#724.

Standalone runs are usually set up by Polaris, whose documentation covers creating, building and running tasks and suites. A standalone run directory needs:

  • the Omega executable, built as described in Standalone Build;

  • the configuration file, omega.yml, in the same directory as the executable (Configuration);

  • a mesh file and an initial condition, read by the streams in the configuration (Mesh Files, Initial Conditions and Restarts).

What a run writes is described in Logging, Timing and Error Messages.
