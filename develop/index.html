Omega

The Ocean Model for E3SM Global Applications (Omega) is a global ocean model under development by the E3SM ocean team. It is initially eddy-resolving, with a non-eddying configuration to follow.

The model is written in C++ using the Kokkos framework for performance portability. Omega is based on the TRSK formulation for geophysical models on unstructured meshes. The first version of Omega is primarily a direct port of the MPAS-Ocean component of E3SM, for comparison purposes.

Development takes place at https://github.com/E3SM-Project/Omega.

How these docs are organized

Each part answers one kind of question:

  • The User Guide answers how do I set up and run Omega, and what can I control? It covers building, running, configuration, input and output, and the model options.

  • The Developer Guide answers how do I work on the code? It covers the development environment, contributing, the framework classes, how the ocean model is put together, and how-to recipes.

  • The Technical Guide answers what does the model compute, and why? It holds the equations, their discretization and the parameterizations.

  • The Design Documents record what we were thinking when we built it. They are frozen when written; the guides describe the code as it is.

Running Omega standalone is done through Polaris, whose documentation covers setting up and running tasks and suites.
