Design Documents

Frozen records

Each design document records what we were thinking when a part of Omega was designed. It is not updated as the code changes, so it may no longer match the code. The User Guide, Developer Guide and Technical Guide describe the code as it is.

New designs start from the template; see Documentation for how to write one.
